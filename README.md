# ghcr-test

A standalone auto-built docker image to test loaders from

(github itself builds the image automatically on push, and then also hosts it in its free related ghcr.io repository)

my [/ppbrown/portainer-test](https://github.com/ppbrown/portainer-test) repo uses this.

Note that for fun with testing, there are two seperate branches (main and staging) and each has unique tags.
